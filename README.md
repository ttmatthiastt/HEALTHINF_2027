HEALTHINF 2027 – Research Appendix

This repository contains the materials used for the HEALTHINF 2027 research project on extracting Barthel ADL and Lawton IADL functional scores from geriatric consultations using LLMs.

Repository contents

prompts/ – The four prompt styles used in the experiment.

scripts/ – Scripts used during the experiment and evaluation.

appendix.md – The appendix in Markdown format.

appendix.pdf – The appendix in PDF format.

The prompts and scripts document the experimental setup, while the appendix provides additional details about the method and scoring. This repository is intended to support the accompanying paper.
